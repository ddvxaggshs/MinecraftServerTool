# Minecraft Relay 3.10.2

修复关服上传超时后错误进入 Recovery required，以及 Resolve World 备份历史耗时过长的问题。

- 上传允许最多 30 分钟，每 15 秒显示等待进度。Git 命令超时会清理它启动的子进程，避免继续卡住。
- 上传响应丢失后核对 GitHub 上的提交和服主锁，已成功保存的会话不会被误判为同步失败。
- 上传前记录目标提交；重启后使用 Recover & Sync 可以识别已经完成的上传，不会重复上传或释放其他服主的锁。
- Resolve World 只备份 GitHub 尚未保存的本地历史，保留世界快照和本地备份分支，避免重复打包全部旧历史。
- Resolve 在选择世界版本之前备份失败时，会释放本次新建的临时锁，保留本地文件；原有恢复会话的锁仍受保护。

通过 20 项隔离回归测试，并验证打包后的 Windows EXE 正常启动与读取服务器状态。

已有独立 updater 的用户：正常关服并完成同步后，重新启动 launcher.exe 或主程序，启动检查会自动获取本次更新。更新保留 data、配置、存档和 Playit。

新安装：将 updater.exe 放进独立文件夹运行，或下载 MinecraftManager-windows.zip 解压。旧版尚无独立 updater 的用户，需要先使用本次 Release 的 updater.exe 完成迁移。
