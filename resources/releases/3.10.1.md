# Minecraft Relay 3.10.1

## 模组管理

- 新增 **Mods** 下拉菜单，显示服务器 `mods/` 中各个 JAR 的名称、版本和启用状态。
- 直接读取 JAR 元数据识别名称，无需联网；支持 Fabric，并可展示 Quilt / Forge 元数据。
- 支持加入本地 Fabric 服务端 JAR，以及启用、禁用、移除操作。禁用采用 `.jar.disabled`，移除前保留本地副本。
- 每次操作自动将对应模组文件的改动提交并推送到服务器 Git 仓库；使用独立 Git 暂存区，不夹带世界存档、配置或其他已暂存文件。
- 同步中断后可通过 **Retry sync (mods only)** 重试，或 **Cancel pending change** 恢复原文件。事务记录及文件副本保存在 `data/mod-transactions/`。

模组修改需要所有服主停服，且本地分支与 GitHub 已发布提交一致。普通 **STOP & SYNC** 仍会保存并上传世界进度。本功能不自动安装前置依赖，最终版本及依赖兼容性仍由 Fabric 启动检查。

## 更新

正常关服并完成同步后，重新打开 `launcher.exe`，程序会自动检查更新。现有 `data/`、服务器目录及备份会保留。

首次安装可下载 `updater.exe` 放到固定文件夹运行，或下载完整程序包 `MinecraftManager-windows.zip`。

## 验证

已验证加入、启用、禁用、移除操作，以及世界文件同时存在已暂存和未暂存修改时的提交隔离。已覆盖上传失败、成功回执丢失、取消恢复、改名中断、服主锁替换等场景，并通过 Windows EXE 启动检查。
