# Minecraft Relay 3.10.0

## 新功能

- 新增 **MANUAL BACKUP** 手动备份按钮。支持停服备份和开服期间备份，ZIP 保存在安装目录的 `data/manual-backups/`，不会自动上传到存档 Git 仓库。
- 在线备份先等待服务器暂停自动保存并完成落盘，再复制世界文件；无论备份成功或失败，都会尝试恢复自动保存。备份期间禁用冲突操作，避免误关程序。
- 右上角新增实时统计：在线总人数、真人 / Carpet 假人数、Java 内存占用。
- 人数约每 5 秒刷新，内存每 2 秒刷新。支持 Carpet 的 fake / shadow 玩家；Scarpet 查询不可用时回退到总人数，假人数显示未知。

统计针对本机启动的 Minecraft 服务器。内存为 Java 进程的物理工作集，包含堆和原生内存，不是配置的最大堆容量。

## 更新与安装

- 已使用新版独立 updater 的用户：正常关服并完成同步后，重新打开 `launcher.exe`；程序会检查并安装更新。
- 首次安装：下载下面的 `updater.exe`，放到一个固定的空文件夹中运行。
- 老版本迁移：正常关闭程序，将 `updater.exe` 放在原来的 `data/` 文件夹旁运行。个人配置、存档及备份会保留。
- 完整离线程序包为 `MinecraftManager-windows.zip`。Minecraft、Git、Java 和 Playit 的初次配置仍由安装向导处理。

## 验证

已通过隔离的真实 Fabric + Carpet 假人统计和在线备份测试，以及超时、磁盘写入失败、保存恢复失败、世界文件变化等异常测试；已验证 Windows 打包程序启动。
